# AnyWare Sales AI 利用マニュアル（下書き）

> 最終確認後に完成版へ更新する。対象読者: 株式会社AnyWare の営業担当者・管理者（非エンジニア含む）。

## 構成案

1. このシステムでできること（全体像・処理の流れ図）
2. ログインとアカウント
   - URL（Vercel）、ログイン方法、ログアウト
   - 利用者の追加（`npm run auth:create-user`）と削除（Neon Console）
3. ダッシュボードの見方（各指標の意味）
4. 企業を探す
   - 検索条件の入力方法と件数の目安
   - 進捗画面の読み方（発見 / 登録 / 新規 / 対象外 / クロール / 解析）
   - 処理が止まって見えるときの対処（今すぐ処理を実行 / 失敗ジョブ再実行）
5. 企業一覧
   - フィルタ・ソートの使い方（営業ランク、採用課題、SNS、Web、営業拒否除外 など）
   - CSV エクスポートと列の意味
6. 企業詳細
   - 基本情報 / 公式サイト / 連絡先 / SNS / 採用状況
   - AI分析（各スコアの定義、A〜D ランクの意味、事実と推測の違い、Evidence の見方）
   - 公式サイトが「要確認」のときの設定方法
   - 連絡可否（営業拒否）の意味と手動上書き
   - 再解析 / AI分析のみ
7. 企業を手動追加
8. ジョブ画面・ログ画面の見方（失敗時の確認手順、AI API 使用量）
9. 営業拒否企業の扱い（suppression_list、将来の自動送信からの除外）
10. 運用ルールと注意点
    - クロール頻度・robots.txt・個人情報の扱い
    - メールアドレスは推測しない（公開情報のみ）
    - API コスト（Claude / GビズINFO）と DATA_MODE
11. 管理者向け設定
    - 環境変数一覧、Vercel / Neon の設定場所、Cron の頻度
    - モデル変更（ANTHROPIC_MODEL）、クロール上限（CRAWL_MAX_PAGES）
12. トラブルシューティング FAQ
13. 用語集（営業スコア、営業ランク、Evidence、ジョブ、要確認 など）
14. 次フェーズ（Phase 4以降）で追加予定の機能

## 反映したい実運用メモ

- Neon Console の Create user はパスワードを設定できないため、利用者作成はコマンドで行う
- Vercel Hobby プランでは Cron が1日1回のため、検索進捗画面を開いたままにするか「今すぐ処理を実行」を使う
- ログイン画面に赤字で不足設定が表示される（NEON_AUTH_BASE_URL / NEON_AUTH_COOKIE_SECRET）
